\# AI Validation



\## What I asked AI to help with



I used ChatGPT to help organize my Windows 11 FAQ and make sure each entry included the required user goal, tool path, steps, evidence, and escalation note. I also used it to help clean up the wording of my support notes and make them easier for a user to understand.



\## Instructions I tested on the live Windows 11 system



I tested each FAQ path on my Windows 11 virtual machine before including it in the FAQ. I tested the following:



\- Settings > Accessibility > Text size

\- Settings > Bluetooth \& devices > Printers \& scanners

\- Task Manager > Processes > Memory

\- Control Panel > Programs > Programs and Features

\- Windows Search > Storage settings > System > Storage



I took screenshots while testing the different Windows tools to document that I was able to reach each location. For the text size issue, I tested different sizes and settled on 150% as a comfortable text size.



\## AI suggestion I revised



One suggestion from ChatGPT was to create an FAQ about changing the default printer. When I tested the instructions, my Windows 11 VM only had Microsoft Print to PDF available. Because I could not actually test switching between multiple printers, I changed the FAQ to "How do I find and manage my printers in Windows 11?" This better matched what I was able to verify on my system.



\## Wording I changed for a non-technical user



While working on the text size FAQ, I wanted the instructions to focus on what the user was trying to accomplish instead of using technical display terminology. I used "Make text easier to read" and told the user to move the slider to their preferred size rather than telling every user to set it to 150%.



The 150% setting was the result of my test, but another user may prefer a different size. This made the instructions clearer and more useful for someone who may not be familiar with Windows display and accessibility settings.
