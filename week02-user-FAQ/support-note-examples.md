\# Support Note Examples



\## 1. Resolved User Navigation Issue



\*\*Issue:\*\* User reported that text was too small after the Windows 11 refresh.



\*\*Support note:\*\* Guided the user to Settings > Accessibility > Text size. The user adjusted the text size to 150% and confirmed that the new size was comfortable to read. No additional display issues were reported. Issue resolved.



\---



\## 2. Issue Requiring Escalation or Approval



\*\*Issue:\*\* User requested removal of organization-managed software.



\*\*Support note:\*\* User requested assistance uninstalling an application from the refreshed Windows 11 system. The application may be organization-managed and removal has not been approved. Documented the application and user request. Escalating for approval before making changes to the system.



\---



\## 3. Rewriting an Unprofessional Support Response



\*\*Vague/unprofessional response:\*\*



> User couldn't find the setting. Showed them where it was and now it works.



\*\*Clear support response:\*\*



> User was unable to locate the requested Windows setting after the Windows 11 refresh. Guided the user to the correct setting and verified that they could access it successfully. User confirmed that the issue was resolved.
