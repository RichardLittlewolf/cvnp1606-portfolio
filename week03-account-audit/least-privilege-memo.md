Least Privilege Memo



At ACME, local administrator access should only be given when an employee actually needs it to do their job. Some employees may need admin access to install software, change system settings, or do other tasks that require administrator privileges. Admin access should not be given just because it makes things easier.



If an employee asks for administrator access, there are times when I would escalate the request instead of giving them access. I would escalate it if the protocol says I need approval, if I am not sure they actually need admin access, or if the request seems unusual. I would rather have someone with the right authority review the request than give someone access they don't need.



If an exception is needed, I would want some evidence showing why they need elevated access. This could be a screenshot showing they are blocked from doing something they need for their job. I would also want to know what they need the access for, how long they need it, and who approved it. I would check if there is another way to get the task done without giving them admin access. Once they are done with the task, the admin access should be removed and documented.
