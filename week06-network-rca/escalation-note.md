\# Escalation Note



\## Tier 1 Actions



1\. I can check the user's IP address, default gateway, and DNS settings with `ipconfig /all`.



2\. I can run basic troubleshooting such as ping tests, flushing the DNS cache, restarting the network adapter, and using the Windows network troubleshooter.



\## Actions That Require Escalation



1\. If the problem requires changing the VPN server or VPN configuration, I would escalate the issue to the network or systems team. I would include the user's symptoms, IP address, gateway, DNS settings, and the results of my ping, nslookup, and Test-NetConnection tests.



2\. If the problem requires changing firewall rules or other network infrastructure, I would escalate it to the network team. I would include which resources are failing, when the problem started, what troubleshooting I already completed, and the command results that show where the connection is failing.
