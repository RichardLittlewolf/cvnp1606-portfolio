\# Network Help Instructions



1\. Open your web browser and try going to a website you normally use, such as Microsoft.com. If the website opens, your internet connection is working.



2\. If the website does not open, right-click the network icon in the bottom-right corner of the screen and open the network settings.



3\. Run the Windows network troubleshooter and follow the steps it gives you.



4\. Click the Start button and type `cmd`. Open Command Prompt.



5\. Type `ipconfig /flushdns` and press Enter. You should see a message saying the DNS Resolver Cache was successfully flushed.



6\. Close Command Prompt and try opening the ACME website or shared drive again.



7\. If regular websites work but ACME resources still do not work, stop and call the helpdesk. Tell the technician that your internet works but you still cannot reach ACME resources.



8\. If you see an error message, a yellow warning icon on the network connection, or the problem comes back after following these steps, call the helpdesk instead of changing any other settings.
